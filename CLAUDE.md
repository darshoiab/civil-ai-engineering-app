# Project: Civil Engineering AI App

## Objective
Build a lightweight web app for civil engineering tasks:
- JKSSR-based estimation
- BOQ generation
- Quantity calculation
- Soil bearing capacity tools

## Instructions for Claude
- Always write clean, modular code
- Prefer simple HTML, CSS, JavaScript (no heavy frameworks)
- Avoid large dependencies (low RAM environment)
- Output JSON cleanly when needed
- Keep files small and readable

## Folder Rules
- frontend/: UI files
- backend/: logic
- data/: JSON files (SSR rates)
- utils/: helper scripts

## Current Task
Start with a simple estimation calculator using JSON rates
